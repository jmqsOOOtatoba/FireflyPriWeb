Feasibility Report · 可行性评估

把 Firefly 改造成 UTTU 风格，
可行吗？

基于对 uttu.merui.net 前端样式的静态源码分析（HTML + 两份生产 CSS，共约 101 万字符），对照本仓库（Astro 7 + Tailwind 4 + Stylus）的现有主题架构，给出分层改造评估。

分析日期 2026-10-10 · 数据来源 /_astro/BaseLayout.DKH0N26w.css · /_astro/index.BtSDwVcQ.css
结论：可行，且性价比分层明显

两站同为 Astro + Tailwind 4 技术栈，设计令牌（颜色 / 字体 / 圆角）可以直接映射进 Firefly 的 @theme 与 variables.styl。建议按 L1→L4 分层推进：L1–L2 是「换个皮肤」，风险低；L3–L4 是「换成游戏菜单」，会动内容架构，需单独评审。不建议像素级复刻——UTTU 是《重返未来：1999》同人档案站，其图像素材、菜单式首页与博客的内容形态并不匹配。

UTTU 的设计 DNA

从生产 CSS 中提取的实际生效值，不是目测估计。

COLOR色板：暖橙主色 + 奶油纸白 + 近黑底

品牌橙色阶以 Tailwind 自定义 reverse-* 命名，正文与描边统一使用奶油色 foundation-*，背景是带噪点的暖黑。整站没有冷色，色温非常统一。

TYPE字体：衬线展示 + 无衬线正文 + 装饰体

字体用途说明
Work Sans Variable全局正文（html 默认 font-family）可变字重 100–900，按 unicode-range 切子集
Playfair Display Variable标题 / 弹窗大字（衬线）弹窗标题「future」斜体橙字即出自这套
Cinzel Decorative装饰性大写标题古典刻本感，UTTU logo 区风格
Raleway Variable辅助无衬线次级信息
Noto Serif JP / Noto Sans (CJK)中日韩文本可切换（data-cjk-pref），还有无障碍字体选项 Atkinson Hyperlegible / OpenDyslexic

LAYOUT结构：游戏主菜单式首页

  • 图片按钮导航——Story / Profiles / Music / Gallery 全是预渲染 webp 图片（如 btn-story.webp 371×126），带 4° 旋转摆放，不是 HTML 文字按钮。
  • 5px 奶油描边——面板统一 border-foundation-100 5px 实线框，圆角很小（0.25–0.375rem），是「卡纸/档案卡」质感，不是现代大圆角卡片。
  • 噪点暗底——全页近黑暖底 + 噪点纹理，背景艺术图 webp（bg-home 等）分层叠放。
  • 进场弹窗——首访先出设置弹窗（语言 / 光标 / Loader 皮肤），游戏化仪式感。

MOTION动效：克制但有性格

  • 雨丝——首页固定容器内 1px 白色渐变线条按 keyframes 下落，移动端自动关闭。
  • 自定义光标——cursor:none + #custom-cursor 双层伪元素跟随，可在设置里关闭。
  • clip-path 分段揭示——标题按 segment0→4 的 inset 动画逐段「刷」出来。
  • 过渡参数——颜色过渡 150ms 居多；按钮 bg-reverse-500 hover:bg-reverse-700；黑胶唱片图片常旋。另有 Astro View Transitions（data-astro-transition-scope）负责切页。

与 Firefly 的架构对照

决定「能不能改」的是技术栈，决定「该不该改」的是内容形态。

维度UTTU（目标风格）Firefly（现状）兼容性
框架Astro（View Transitions）Astro 7 + Svelte 岛屿 + Swup同栈，无迁移成本
样式系统Tailwind 4 + 自定义色阶（hex）Tailwind 4 + Stylus + CSS 变量（oklch 色相可调）token 可直接映射
主题模型固定暗色单主题（另有国服开关等）亮 / 暗双主题 + 全局色相滑块需决定保留双主题还是切单暗色
正文可读性奶油字 #ece5d9 / 近黑底，对比度高亮色为主，文章页 prose 体系暗底奶油字对博客完全成立
导航形态图片按钮游戏菜单文字导航 + 侧栏组件（播放器/天气/看板娘）图片菜单需要美术资源，且挤占功能位
品牌资产Reverse:1999 同人素材（版权方 Bluepoch）自有萤火虫品牌只能借设计语言，素材必须自制
内容重心档案检索 / 图鉴 / 剧情浏览长文阅读 + 评论 + 友圈文章页排版优先级 > 菜单炫技

分层实施路线

每层独立可交付、可回退。建议至少做完 L2 再评估是否继续。

L1TOKENS

设计令牌移植 —— 换色换字

在 @theme / variables.styl 引入 reverse 橙色阶与 foundation 奶油色阶，把 --primary、--page-bg、--card-bg、--line-divider 等核心变量映射到 UTTU 取值；字体侧在 fontConfig 增加 Playfair Display（标题）+ Work Sans（正文），CJK 沿用现有汉仪文黑或换 Noto Serif 增加「刻本感」。噪点纹理用一张 SVG data-URI 铺底。

工作量：小（半天～1天） · 风险：低 · 全站即时变脸
L2COMPONENTS

组件皮肤 —— 卡片 / 按钮 / 导航

卡片改成 5px 奶油描边 + 0.375rem 小圆角 + 暖黑面板；主按钮改 bg-reverse-500 → hover:reverse-700；导航栏、标签、文章元信息、代码块顶栏全部跟随色板；给标题补 clip-path 分段揭示动效。这一层做完，「像不像 UTTU」已有七八成。

工作量：中（2–4天） · 风险：中（需逐页目检亮/暗两套）
L3EFFECTS

氛围特效 —— 雨丝 / 自定义光标 / 噪点动效

雨丝容器（移动端自动禁用）、自定义光标（设置里可关）、黑胶旋转装饰等。全部是独立图层，不碰内容架构。注意：自定义光标会影响可访问性，务必保留开关——UTTU 自己也提供了关闭选项。

工作量：小-中（1–2天） · 风险：低（独立图层，可单独回退）
L4RESTRUCTURE

形态改造 —— 首页游戏菜单化

把首页改成图片按钮式主菜单 + 进场弹窗 + 分屏面板。这层会与现有首页架构（侧栏播放器、友链、置顶文章等 Svelte 岛屿）正面冲突，还需要成套美术资源（按钮图、背景图、Logo 变体）。除非你想把博客彻底改成「个人门户 / 档案馆」形态，否则不建议。

工作量：大（1–2周 + 美术） · 风险：高（信息架构重做）

风险清单

  • 版权素材红线——UTTU 的按钮图、角色图、背景均属 Bluepoch 资产或同人创作，只能借「设计语言」，所有图像资源必须自制 / 授权。
  • 双主题决策——UTTU 是单暗色站；Firefly 有亮暗双主题和色相滑块。橙×奶油在亮色主题下需要另一套取值（奶油底 + 深橙字），否则会翻车。
  • 文章页可读性——长文是博客的命。暗底奶油字对比度足够（#ece5d9 on #1a1919 ≈ 13:1），但 prose 内的引用块、代码块、表格都要随主题重调，不能只改外框。
  • 性能预算——噪点、雨丝、自定义光标都是廉价特效，但背景大图要走本仓库已有的 LQIP / resize 管线，别硬塞 2MB webp。参考 18文章 的性能优化基线（forced-reflow、LCP 目标）。
  • 既有资产冲突——GreatVibes 装饰字体是死文件（见性能优化交接记录），换字体体系时顺手清理，别叠床架屋。

建议

PLAN先 L1 + L2，一周内看到成果

第一步只动令牌和组件皮肤，就能让全站获得「UTTU 味」的八成观感，且随时可回退；雨丝和光标（L3）作为甜头按需添加；L4 首页形态改造单独立项、做好信息架构评审再动。改造期间用 pnpm check 的 17-error 基线与 18文章 的性能基线做回归参照，视觉验收走本机 dev server + Playwright MCP 截图对比。
