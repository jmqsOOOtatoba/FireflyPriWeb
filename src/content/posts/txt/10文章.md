# 第三方Agent API Key获取

目前市面上有许多主流Agent，如~~豆包~~:spoiler[太蠢了哈哈]！千问、文心一言、智谱GLM、DeepSeek、Kimi。本文以**小米MIMO**模型为例演示如何让获取API KEY，推荐读者使用DeepSeek，GPT等模型，不考虑价格因素，目前是市面上相对较强的模型。

1. 访问[**Xiaomi MiMo Home**](https://mimo.mi.com/)，点击API接入
2. 点击API KEYS—新建API KEY—输入KEY的名称，随后即可生成API KEY
> [!WARNING] 警告：API KEY只会出现一次，请及时复制之后保存。

3. 将API KEY填入CC Switch，如果您不想使用CC S作为API中转，可以根据不同Agent的官方文档教程来进行部署，本文不作介绍。
# CC Switch部署

访问[CC Switch 官方网站 - AI 编程工具统一管理平台](https://ccswitch.io/zh/)，下载安装即可

## CC Switch快速上手

### 第一步：添加供应商
1. 点击主界面右上角的 + 按钮
2. 在「预设」下拉框中选择你的供应商
• 常用预设：智谱 GLM、MiniMax、DeepSeek、Kimi、PackyCode
• 或选择「自定义」手动配置
3. 填写 API Key
4. 点击「添加」
![](https://ccswitch.io/docs/assets/image-20260108002807657.png)
### 第二步：切换供应商

添加完成后，供应商会出现在列表中。

**方式一：主界面切换**

- 点击供应商卡片的「启用」按钮

**方式二：托盘快速切换**

- 右键系统托盘图标
- 直接点击供应商名称

完成以上步骤后，您可以自由的使用Codex接入的第三方API，请注意每次启动Codex之前都需要开启CC Switch
