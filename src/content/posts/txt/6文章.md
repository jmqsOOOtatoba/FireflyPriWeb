## 利用现有组件添加音乐播放器

> 依旧是可以直接利用MD语法直接再文章中嵌入组件，并且实现默认自动播放。

## 效果展示（音频源网易云示例）

::music{server="netease" type="song" id="2148135602" volume="0.3" loop="true" }

## 使用说明

### 直接URL方式

```markdown
::music{url="https://example.com/song.mp3" title="歌曲标题" artist="艺术家" cover="封面URL"}
```

### 网易云音乐方式

```markdown
::music{server="netease" type="song" id="1901371647" title="歌曲标题" artist="艺术家"}
```

## 参数说明（基本和主页播放器组件相同）

| 参数 | 说明 | 示例 |
|------|------|------|
| `url` | 音乐文件URL | `url="/assets/music/song.mp3"` |
| `server` | 音乐平台 | `server="netease"` |
| `id` | 歌曲ID | `id="1901371647"` |
| `type` | ID类型(默认song) | `type="song"` |
| `title` | 歌曲标题 | `title="我的歌曲"` |
| `artist` | 艺术家 | `artist="艺术家"` |
| `cover` | 封面图片URL | `cover="https://example.com/cover.jpg"` |
| `autoplay` | 自动播放(默认true) | `autoplay="true"` |
| `loop` | 循环播放(默认false) | `loop="true"` |
| `volume` | 音量0-1(默认0.7) | `volume="0.5"` |


### 代码实现

1. rehype-component-music-player.mjs（组件）
解析 ::music{...} 语法
支持参数：url、server、id、type、title、artist、cover、autoplay、loop、volume

2. music-player-script.js（脚本）
音频播放控制（播放/暂停/进度/音量）
Meting API 集成（网易云、QQ音乐等）
页面切换时自动暂停
自动播放处理

3. music-player-styles.css（样式）
白灰渐变背景
圆形封面（仿B站头像）
暗色模式适配

4. astro.config.mjs（配置）
```
import { MusicPlayerComponent } from "./src/plugins/rehype-component-music-player.mjs";
// ...
components: {
    music: MusicPlayerComponent,
}
```

5. Layout.astro（布局）

```
<link rel="stylesheet" href="/plugins/music-player-styles.css">
<script is:inline src="/plugins/music-player-script.js"></script>
```
