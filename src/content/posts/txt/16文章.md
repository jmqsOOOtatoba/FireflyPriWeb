# Win11 资源管理器大小列只显示 KB？开启 KB / MB / GB 自适应显示完整教程

> Windows 11 的大小列动辄一长串 KB 数字，肉眼完全无法换算。好消息是微软已经原生支持自适应单位了；坏消息是灰度推送可能轮不到你。本文给出从"先试免费零风险的更新"到"ViveTool 强制开启功能 ID 61014711"的完整方案，附回滚方法。

## 问题

Windows 11 的文件资源管理器切换到"详细信息"视图后，大小列长期以来**一律用 KB 显示**：一个 4 GB 的文件写成 `4,194,304 KB`，几十 GB 的文件就是一长串数字，肉眼完全无法换算，只能点开属性才能确认实际大小。

## 背景：微软已经原生支持了

2026 年 7 月起，微软开始推送这个改进：

- **7 月可选更新 KB5101684**：24H2 升到 Build 26100.8973，25H2 升到 Build 26200.8973，详细信息视图的文件大小改为按实际大小自适应显示 KB / MB / GB；
- **8 月累积更新 KB5121003**：24H2 到 26100.9168，25H2 到 26200.9168，该功能随安全更新正式向所有用户推送；
- 在更早的 25H2 Beta / Experimental 预览版（26220.8370、26300.8376）中，这个功能默认隐藏，功能 ID 为 **61014711**，需要手动开启。

也就是说：**先检查 Windows 更新，装完再重启资源管理器，很可能什么都不用改就好了。**

但我在自己的机器上实测（25H2，Build 26200.9168，已包含 8 月更新）：装了更新、重启了资源管理器，大小列**依然全是 KB**。原因是这类功能采用 CFR（受控功能放量）分批推送，同一个版本号的机器生效时间可能不同。这时就轮到 ViveTool 出场。

## 方法一：先更新系统（免费、零风险）

1. 设置 → Windows 更新 → 检查更新，安装 2026 年 7 月及之后的所有更新；
2. 打开任务管理器（Ctrl+Shift+Esc）→ 找到"Windows 资源管理器" → 右键"重新启动"；
3. 打开任意有大文件的文件夹，切到详细信息视图，看大小列是否已显示 MB / GB。

生效了就不用往下看了。

## 方法二：ViveTool 强制开启（更新后仍是 KB 时用）

ViveTool 是微软隐藏功能（Feature ID）的命令行开关工具。

### 1. 下载 ViveTool

任选其一：

- **winget（推荐）**：终端执行

  ```
  winget install --id thebookisclosed.Vive --accept-package-agreements --accept-source-agreements
  ```

- **手动下载**：GitHub 仓库已从 `thebookisclosed/ViVeTool` 改名为 **`thebookisclosed/ViVe`**（旧地址会 404），到其 Releases 下载 `ViVeTool-v0.x.x-IntelAmd.zip`，解压到任意目录。

> 注意：如果你的网络直连 GitHub 超时，下载需要走代理；winget 的下载进程不读系统代理，卡住不动时请换手动下载 + 代理，或用 `curl.exe -x http://127.0.0.1:<代理端口> -L -o vivetool.zip <下载地址>`。

### 2. 以管理员身份执行

**必须管理员**（写注册表需要提权，否则会报"拒绝访问"）。打开一个**管理员**终端，执行：

```
ViVeTool.exe /enable /id:61014711
```

验证是否写入成功：

```
ViVeTool.exe /query /id:61014711
```

看到 `State : Enabled` 即成功。

### 3. 重启资源管理器

任务管理器 → Windows 资源管理器 → 重新启动。再看大文件的大小列，此时应该显示 `1.25 MB`、`3.72 GB` 这样的自适应单位了。

## 如何恢复原状

ViveTool 的修改只是加了一条功能覆盖，随时可逆：

```
ViVeTool.exe /disable /id:61014711
```

然后重启资源管理器即可回到 KB 显示。系统后续大版本更新也可能自动重置该覆盖。

## 常见问题

- **执行 /enable 报"拒绝访问"**：终端不是管理员权限，右键"以管理员身份运行"再执行。
- **开启了、重启了还是 KB**：确认系统已装 2026 年 7 月之后的更新——ViveTool 只是把系统里已有的功能代码"翻到开"，如果系统里根本没有这段代码（更新太旧），开启也无效。
- **对文件夹有效吗？**：大小列对文件夹本身仍不显示大小（这是另一回事，需要第三方工具计算），本功能针对的是文件。
- **只影响详细信息视图**：图标、平铺等其他视图不显示大小数字，自然不受影响。

## 总结

| 方案 | 适用场景 | 风险 |
|---|---|---|
| 装 2026 年 7 月后更新 | 功能已随更新推送 | 无 |
| ViveTool + ID 61014711 | 已是新版本但被灰度卡住 | 低，可随时 disable 回滚 |

亲测环境：Windows 11 25H2（Build 26200.9168），更新后仍显示 KB，用 ViveTool 0.3.4 开启 61014711 并重启资源管理器后生效。
