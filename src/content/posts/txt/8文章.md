# 🗡龙之剑自由相机模组
N网上有个模组我挺喜欢用，可以调整相机镜头，并且反虚化，但是没有汉化并且窗口特别小，在大屏上看眼睛都要花了，于是我简单进行了汉化，并且增添了调整窗口大小的功能。

原版模组[***下载地址***](https://www.nexusmods.com/dragonswordawakening/mods/120)

我的修改版[***下载地址***](https://pan.baidu.com/s/16PkOWTgklbnmFSWf3PzAKw?pwd=9bd8)

> 原版模组描述：移除放大角色时的透明效果，这样你可以欣赏素材或其他内容。还允许配置一些摄像机设置（距离、角色偏移等），默认还能解锁摄像机的俯仰角，这样你就能看天空，嗯嗯。
# 📕使用教程

1. 需要安装[发行版 ·UE4SS-RE/RE-UE4SS](https://github.com/UE4SS-RE/RE-UE4SS/releases)，并且一定要安装最新的版本，如果你已经安装可以忽略此步骤。
2. 下载后解压到`DragonSword  Awakening\DS\Binaries\Win64\`路径下。
3. 下载模组，并解压到`DragonSword  Awakening\DS\Binaries\Win64\ue4ss\Mods`目录下
4. 启动游戏，当完全进入游戏后按**F5**即可唤出模组界面。

# 📷 CameraTweaker 设置面板功能详解

## 🔘 开关类设置

| 设置 | 说明 |
|------|------|
| **启用相机调整** | **总开关**。关闭后所有相机参数恢复游戏默认值。 |
| **禁用近距离透明** | 开启后，角色靠近镜头时不会变透明（原版游戏会变透明）。需要切换角色后生效。 |
| **应用到载具** | 开启后，相机参数也会应用到载具上。默认关闭。 |

---

## 📐 实时更新选项（拖动滑块立即生效）

| 设置 | 默认值 | 说明 |
|------|--------|------|
| **最小俯仰角** | -90° | 视角能往下看的最低角度。原版是 -45°，改成 -90° 可以直接看地面。 |
| **最大俯仰角** | 90° | 视角能往上看的最高角度。原版是 45°，改成 90° 可以直接看天空。 |
| **相机跟随速度** | 10 | 相机跟随角色移动的速度。值越大，相机跟得越紧，不容易"飘"。设为 0 则禁用跟随延迟。 |
| **相机相对位置 X/Y/Z** | 0 | 相机相对于角色的直接偏移量。X=前后，Y=左右，Z=上下。 |

---

## ⏳ 非实时更新选项（切换角色后生效）

| 设置 | 默认值 | 说明 |
|------|--------|------|
| **相机最近距离** | 0 | 拉近镜头的最小距离。值越小，镜头能离角色越近。 |
| **相机最远距离** | 600 | 拉远镜头的最大距离。值越大，镜头能离角色越远。 |
| **近景插槽偏移 X** | -100 | 镜头拉近时，相机的前后位置。负值=在角色前方（防止镜头穿进身体）。 |
| **近景插槽偏移 Y** | 30 | 镜头拉近时，相机的左右位置。正值=偏右，负值=偏左。 |
| **近景插槽偏移 Z** | 75 | 镜头拉近时，相机的高度。75 大约是头部高度。 |
| **远景插槽偏移 X** | 0 | 镜头拉远时，相机的前后位置。 |
| **远景插槽偏移 Y** | 60 | 镜头拉远时，相机的左右位置。 |
| **远景插槽偏移 Z** | 125 | 镜头拉远时，相机的高度。 |

---

## 🖥️ 面板设置

| 设置 | 说明 |
|------|------|
| **面板宽度** | 调整设置面板的宽度（300-1200）。 |
| **面板高度** | 调整设置面板的高度（400-1000）。 |
| **应用面板大小** | 点击后保存并重建面板，使尺寸更改生效。 |

---

## 🔘 底部按钮

| 按钮 | 说明 |
|------|------|
| **应用并保存** | 应用所有相机参数并保存到配置文件。 |
| **重置** | 恢复所有设置为默认值。 |

---

## 💡 使用建议

1. **想要自由视角**：把俯仰角范围调到 -90° ~ 90°
2. **想要更近的特写镜头**：把相机最近距离调小
3. **想要更稳定的镜头**：把相机跟随速度调高
4. **想要肩越视角**：调整近景插槽偏移 Y（左右）和 Z（高度）

**按 F5 打开面板，试试调整这些参数！** 🎮
